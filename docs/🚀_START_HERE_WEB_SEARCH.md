## 🎯 TOGGLE WEB SEARCH

### **To Disable:**

1. Click the 🌐 Globe icon
2. Icon turns gray
3. Tooltip shows: "Web search disabled"
4. Agent uses only internal knowledge

### **To Re-Enable:**

1. Click gray 🌐 icon
2. Icon turns orange with pulse
3. Tooltip shows: "🌐 Web search enabled"
4. Agent can search internet again

## 📞 TROUBLESHOOTING

### **If Globe Icon Missing:**
- Refresh browser (Ctrl+R)
- Clear cache
- Check console for errors

### **If Web Search Not Working:**
- Check ANTHROPIC_API_KEY in .env
- Verify Claude Sonnet 4+ model selected
- Check console logs for errors

### **If Citations Not Showing:**
- Ensure web search is enabled (orange icon)
- Try a query that needs current info
- Check that model supports web search
