## 📊 JSON Schema Structure

### **Compact Format:**
```json
{
  "agent": "Latenite AI",
  "role": "autonomous_full_stack_engineer",
  "task": "user_request_here",
  "terminal": "last_500_chars",
  "iter": 1,
  "hist": [{"t":"thought","a":"action","o":"observation"}],
  "os": "windows|linux|macos|docker",
  "rules": ["core_rules"],
  "actions": ["special_commands"],
  "format": "THOUGHT|ACTION",
  "ex": {"t":"example_thought","a":"example_action"}
}
```

### **Why This Works:**
- Claude AI understands JSON schemas natively
- Structured data = faster parsing
- No ambiguous text = better compliance
- Smaller payload = faster transmission
- Clear format = consistent responses
