### **Suggestion Generation Flow:**
```

    ↓
Error Detection (regex patterns)
    ↓
Context Analysis (last command, path)
    ↓
Prediction Logic (workflow patterns)
    ↓
Generate Suggestions Array
    ↓

    ↓
User Clicks "Apply" → Execute Command
```
